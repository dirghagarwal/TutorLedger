# TutorLedger Roadmap

TutorLedger is delivered in small, reviewable milestones. Each milestone keeps the app runnable and preserves a clear source of truth for every domain entity.

## MVP

- [x] Foundation and dark dashboard shell
- [x] Students read-only module with typed profiles
- [x] Attendance engine foundation
- [x] Recurring schedule engine foundation
- [x] Payments engine foundation
- [x] Session engine foundation
- [x] Calendar month view with generated sessions
- [ ] Calendar week and day views
- [ ] Attendance actions and session completion workflow
- [ ] Payment entry and payment history workflows

## v1.0

- [x] SQLite and Prisma persistence
- [ ] Search, filtering, editing, and archival for students
- [ ] Calendar drag-and-drop rescheduling
- [ ] Monthly and class-wise invoicing
- [ ] Reports and exports
- [ ] Settings, backup, and import/export
- [ ] AI command parsing with structured actions
- [ ] PWA installation and offline-friendly read views

## v2

- [ ] Multi-tutor workspaces and permissions
- [ ] Guardian-facing communication and reminders
- [ ] Automated recurring invoices and receipts
- [ ] Advanced analytics and forecasting
- [ ] AI-assisted planning, summaries, and anomaly detection
